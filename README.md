# Still Discussing

A delay-excuse generator in the deadpan voice of a perpetually-postponed
corporate funding update. Click **Generate the next excuse** for another one.

- 300+ hand-written excuses, shuffled so the whole set appears before any repeat
- No backend, no dependencies — a single static `index.html`
- Warm palette + Poppins, hosted on GitHub Pages

Open `index.html` locally, or visit the Pages URL.
